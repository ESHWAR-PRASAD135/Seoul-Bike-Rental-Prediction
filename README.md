Seoul Bike Rental Prediction

Project Overview

This project predicts bike rental demand in Seoul using machine learning and real-time weather data. It uses a Linear Regression model and a Streamlit web application to display predictions.

Technologies Used

- Python
- Machine Learning (Linear Regression)
- Pandas and NumPy
- Scikit-learn
- Streamlit
- Open-Meteo Weather API

Features

- Fetches real-time weather data for Seoul.
- Predicts bike rental demand based on selected inputs.
- Provides a simple interactive web interface.

How to Run

1. Install Python.
2. Install the required libraries.
3. Run the application:

python -m streamlit run app.py
